# NekoBot

Простой ИИ Телеграм-бот использующий Ollama.

## Установка 

Для установки можно воспользоваться `cargo install`:
```bash
cargo install --git https://github.com/egevtech/nekobot
```

## Использование

Бот использует два конфигурационных файла:
1) `const_config.toml`:
```toml
[ollama]
url="..." // Можно пропустить это поле, тогда будет взят дефолтный url

[telegram]
token="..." // Токен бота, полученный через Bot Father
message_length=4096 // Максимальная длина сообщения в тг, будет "нарезаться" на сообщения этой длины
callsign="..." // Слово в сообщении, на которое будет откликаться бот, например, "Неко, привет"

[database]
db="..." // Путь к файлу, в котором будет база данных, например, "./bot.db"
```
2. `dyn_config.rhai`
```rhai
#{
  ollama: #{
    model: "..." // имя модели из ollama
    thinking: true/false // Включить думалку(если модель умеет думать)
    sys_prompt: "..." // Системный промпт для модели
  }
}
```
